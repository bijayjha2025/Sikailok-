# Introduction to Python	
Python is a high-level, easy-to-read programming language used to create different types of software and applications. It was developed by **Guido van Rossum** and first released in **1991**. The file extension of a Python source file is **.py(dot-p-y)**.

## Application areas of Python
- Web development
- Mobile applications
- Desktop software
- Artificial Intelligence (AI)
- Machine Learning
- Data Science
- Game development
- Cyber security

## Features of Python
- **Easy to Learn**: Python syntax is simple and easy to understand compared to many other programming languages.
- **Dynamically typed**: Python is dynamically typed language, meaning that we do not need to declare the type of a variable. A variable can also refer to values of different types at different times.
- **Platform Independent**: The same Python programs can generally run on Windows, Linux, and macOS, with little or no modification.
- **Easy to Read**: Python code is written in a clear and readable manner, making it easier to understand and maintain.
- **Free and Open Source**: Anyone can download and use Python for free.
- **Interpreted Language**: Python uses an interpreter instead of a compiler which makes it easier to debug.
- **Object-Oriented**: Python is based on Object-Oriented Programming (OOP) as it allows us to work with objects and classes.
- **Large Library Support**: Python provides many built-in libraries such as math, random, and turtle that helps us to perform different tasks.

## Advantages of Python
- Since Python has very less and simple syntax, it is easier to begin with.
- Compared to languages like C/C++ or Java, same task can be completed using fewer lines of code.
- It has huge collection of libraries because of which ready-made tools are available to make our work easier.
- Through modules, it allows us to reuse the same piece of code. We do not have to rewrite the same code again and again. 

## Disadvantages of Python
- Since Python uses Interpreter not compiler, it is slower than compiled languages like C/C++.
- Python uses more memory than many other programming languages.
- They are comparably less ideal for mobile app development compared to languages like Kotlin, Java
