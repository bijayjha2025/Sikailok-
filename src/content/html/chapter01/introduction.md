# Introduction to HTML

HTML stands for **HyperText Markup Language**. It describes the structure of a web page. HTML uses elements to mark up content such as headings, paragraphs, images, and links.

## A basic HTML document (Structure of HTML)

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, everyone!</h1>
    <p>This is my first web page.</p>
  </body>
</html>
```

## Important parts

- **`<!doctype html>`** tells the browser to use modern HTML.
- **`<html>`** contains the whole document.
- **`<head>`** contains information about the page.
- **`<title>`** sets the browser tab title.
- **`<body>`** contains the visible page content. We perform most of the tasks within this tag.
